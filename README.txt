THELOOP — landing page

ARCHIVOS
- index.html: web completa (HTML, CSS y JavaScript).
- Mascot.png: estrella original, incluida sin modificar.
- Logo.png: logo original.

CÓMO VERLA
Abre index.html en Chrome, Edge o Firefox. Para publicarla, sube los tres archivos manteniendo la misma estructura a tu hosting (por ejemplo, GitHub Pages, Netlify o Vercel).

FORMULARIO
El formulario muestra una confirmación visual, pero todavía no guarda emails en ningún servidor. Para recibir inscripciones reales, conecta el formulario a Formspree, Brevo, Mailchimp o tu propio backend.

ANIMACIÓN
La estrella original se amplía al hacer scroll, el fondo azul asciende y el logo aparece al final de la transición. No se ha redibujado ni editado el archivo de la estrella.
